Расчёт по **непрозрачным sRGB** токенам (не снимок UI): text/panel **15.82:1**, secondary/panelRaised **7.38:1**, muted/panelRaised **3.30:1**, border/panel **1.52:1**, accent/panel **10.73:1**. Два низких значения не закрывают пороги основного текста `4.5:1` и значимых интерактивных границ `3:1`. Нужна проверка фактического фона, alpha, stroke и focus в реальном редакторе, отдельно от декоративных линий. `24×24` — целевой эффективный hit area; иконка может быть меньше. OS DPI и внутренний scale не умножают друг друга повторно.

## Совместимость и статусы компонентов

**Implemented** — класс присутствует в публичном `VoxComponents.h`, не «Production». **Prototype** — есть продуктовый донор, не shared API; **Concept** — только контракт; **Deferred** — потребитель/поддерживаемое поведение ещё не подтверждены. Ни одна строка здесь не претендует на **Production**. Примеры размеров, состояния, binding и план негативных тестов ниже — требования к карточкам при реализации, не результаты проверок.

| Семейство и приоритет | Доказательство / статус сегодня | Shared API и продуктовая граница | Первая приёмка (не выполнена здесь) |
| --- | --- | --- | --- |
| Panel / section / tabs · P1 | `VoxPanel`, `VoxSectionHeader`, `VoxTabBar` — **Implemented** в `components/` | Regions/title, active selection, safe overflow, sane focus order; контент и идентификаторы панелей у продукта. Tabs не равны страницам старого Drums. | Отключённая вкладка не захватывает selection; фокус восстанавливается после hide/split. |
| Knob / encoder / macro / mod ring · P1 | `VoxKnob` — **Implemented**. Inner `juce::Slider`, 270°, 3 размера, bipolar style, caller-set reset/overlay. `VoxEncoder` и полноценный multi-route ring — **Concept**. | Typed plain value/unit, host attachment **в продукте**, единый пользовательский жест. `setModulationAmount` — подсказка рисованию, не DSP readback. Relative encoder только где работает потребитель. | Gesture cancellation/rebind завершают ровно один жест; fine drag, реальный default, numeric reject/escape; не менять base под modulation; не отнимать wheel у scroll. |

## Единый минимум карточки реализации

- Указать owner, typed domain и фактические defaults, разрешённые states, focus и JUCE AccessibilityHandler, валидный keyboard shortcut scope, геометрию и theme. Состояния `disabled` (временно нельзя), `read-only` (значение можно прочитать) и `unavailable` (нет источника) проверять по отдельности; automation, modulation, clip risk и warning не кодировать одним цветом.
- Остаются product-side attachment (`APVTS` у Drums, прямые `RangedAudioParameter` у FX), undo и действующие versioned Project/Program codecs. Предлагаемые `ParameterBinding`, `DisplayValue`, `ControlState`, `TelemetrySnapshot`, `SelectionContext`, `ValidatedEdit` — проектные интерфейсы, не найденные классы. Компонент не пишет в processor из `paint()` и не удерживает RT state.
- К каждому компоненту: unit + негативный тест и integration consumer; 100/125/150/200% Windows и допустимый UI scale; snapshot самого контрола и реального standalone editor **только после разрешения на визуалы**. Текущая `vox_ui_showcase` опциональна (`VOX_UI_BUILD_SHOWCASE`, по умолчанию OFF), а `vox_ui_visual_gate_capture` в своём CMake привязан к старому `VstEngine`. Это не доказательство самостоятельного визуального gate для Drums/FX; отделить test harness от runtime-библиотеки в DS-01/02.
- Подтвердить neutral component boundary минимум в двух применимых контекстах или обосновать платформенный общий primitive. Не заводить Synth-специфические DSP/параметры заранее. Не переносить CSS/React в продукт; [карта браузерных аналогов](../../../apps/vox-music-prototype/docs/JUCE_PORTING_MAP.md) — иллюстрация контракта, не C++ reuse.
