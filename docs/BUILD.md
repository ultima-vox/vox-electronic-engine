# Windows build and validation

Requirements: Visual Studio 2022 Desktop development with C++, CMake 3.22+, Git.
JUCE is pinned to 9.0.1 and fetched during configure.
An offline plugin does not imply that a clean source build can fetch dependencies offline.

## Build

Run from the repository root in PowerShell:

```powershell
git clone https://github.com/ultima-vox/vox-electronic-engine.git
cd vox-electronic-engine
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
cmake --build build --config Release --target package
```

For an existing checkout, start at the configure command after selecting the intended branch.
Use a separate build directory for each toolchain/checkout.

Current VST3 bundle:

```text
build/VstEngine_artefacts/Release/VST3/Vox Electronic Engine.vst3
```

The ZIP filename is generated by CPack from the current product version/platform.
Do not assume it has already been renamed to Trance Engine.
Optional NSIS packaging requires `makensis` and `-DVOX_ENABLE_NSIS=ON`.

The installed binary retains the old product name and identifiers during this docs-only transition.

## UI captures

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DVOX_UI_BUILD_SHOWCASE=ON
cmake --build build --config Release --parallel
```

The current workflow invokes `vox_ui_visual_gate_capture.exe` separately from CTest.
See the [workflow](../.github/workflows/build.yml) for its actual capture arguments.
A showcase render is not proof that the real editor works.

## Acceptance

Run all existing tests without weakening limits.
At integrated milestones verify generated MIDI, automation, project reopen,
transport/loop/seek and offline rendering in the target DAWs. Manual DAW checks
are not required after every technical PR; required automated checks and review
still apply. Build the VST3 product; no separate standalone app is required.
Report actual Windows/DAW build numbers; do not claim a full version range from a single test.
