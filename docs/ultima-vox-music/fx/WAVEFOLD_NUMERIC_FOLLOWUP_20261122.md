# Wavefold ADAA2 numerical follow-up, 2026-11-22

Candidate: PR #169, starting head `f3a30a7b15cf53253f727751715a770885f7b726`; TL review 6008759647. This remains an experimental Draft and HOLD. Sound, the approximately one-sample phase effect, host behavior and listening approval remain open.

Near-coincident inputs caused cancellation in the second divided difference: the reproduced candidate produced 55.511145 for a near-zero alternating input. The fix uses a relative near-coincidence threshold and a mean-value fallback; within a single affine segment it uses the exact segment mean. At a fold corner, the triangle function's Lipschitz bound is gain times the input range; the reference tests measure actual error, not a proof of a global 1e-5 error bound. The outgoing Wavefold history is also retained through type-change crossfade: on a constant 0.125 input, the reproduced maximum step changed from 0.229454704 to 0.00310027599 in the specified rapid-control test.

The 312 deterministic 80-digit Decimal reference cases cover gains, positive and negative corners, repeated and near-coincident values and seeded samples. GCC Linux O0, O3 and ASan/UBSan runs passed; maximum observed error was 6.67100182061e-6. The parallel dry/wet test's maximum mix error was 2.62260437012e-6. Nine coherent sine captures at 2, 5 and 8 kHz, at 44.1, 48 and 96 kHz, were bit-identical to the original candidate; this is limited coverage, not proof of identical sound. Regenerate the fixture with `python3 tools/generate_wavefold_reference.py | cmp - tests/suite/fixtures/FxWavefoldReference.h`. The five FX processor, automation, nonlinear alias, effects and tail CTest targets passed locally; logs and capture comparisons are in `evidence/`.

A paired Linux experiment used the same stress harness on the original and fixed candidate in alternating order, three runs each, without selecting a best run. Each run covered 72 combinations of 44.1/48/96 kHz, 32/64/128/512 samples, 1/4/8 voices and Pattern off/on, with four fully wet Wavefold slots and a Pattern seek. The existing finite-window mean criterion failed in 44 of 72 cases for both versions; the largest observed mean was approximately 0.140363 and the largest original/fixed rounded difference was 2e-7. These short windows do not establish a physical DC offset. Allocation and wrapped pthread lock counts were zero in these Linux runs. Original wall deadline misses were 17, 16 and 6; fixed misses were 0, 25 and 2. CPU misses were 17, 11 and 6 versus 0, 26 and 2. Shared VM scheduling and lack of affinity control prevent a performance conclusion. Full per-case wall/CPU percentiles and all raw trials are retained; the raw archive SHA-256 is `3b69240d9d4e7b2202e7453bd5a01a5c4b1515c220016fbd50bc179f53916bae`.

Windows exact-head build, suite, validator and stress evidence remain separate gates. The optional `fx_wavefold_stress` workflow dispatch runs three trials on a self-hosted Windows runner and stores per-case logs; Windows thread CPU timing can be coarse, and this harness does not instrument Windows locks. No Linux result is a Windows PASS.
