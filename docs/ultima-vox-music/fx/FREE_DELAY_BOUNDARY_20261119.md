# Free Delay transition boundaries and Source keyboard scope

Follow-up to [TL's Delay review](https://github.com/ultima-vox/vox-electronic-engine/pull/156#issuecomment-7036499625) on `6ec58a4`. Implementation and tests: `6d16b923368c1489eda47922b487592f68ea65de`. [Candidate evidence table](ENGINEERING_CANDIDATE_EVIDENCE_20261119.md).

## Free Delay: fix the correction, not the signal path

Blending toward a rounded address that changes with every smoothed sample can still jump by nearly a whole sample during the 5 ms transition. Instead, the entering fade starts from the **previous read head's fractional correction** and takes that correction to zero. The exit correction uses a fixed endpoint, after the raw target holds for at least 5 ms and the float smoother actually stops moving. A new target during exit restarts from the current correction. A never-moved control (including its cold start) still uses the old rounded read. Each channel still uses one interpolating read, with no new delay bank, host latency, parameter IDs, state schema, or feedback policy. Tempo Delay is untouched. Existing projects with moving free Delay can sound different.

- Hand-authored address trajectories force both ramp speeds through half-sample boundaries, reversals, two held plateaus and a move during the exit fade. The previous formula yielded **0.967–0.990 sample** on entry and **0.248–0.251 sample** on premature exit; new maximum excess correction step was **0.002258/0.002079/0.001040 sample** at 44.1/48/96 kHz, respectively. This compares the change in corrected position to the change in raw fractional position, not Doppler motion itself.
- A real first-echo input with a linear reading region crosses the boundary early in the blend. Maximum adjacent-output derivative residual vs continuous reference, **old-formula model → measured new**: **0.000492209 → 0.000001116** (44.1), **0.000490649 → 0.000001008** (48), **0.000494583 → 0.000000522** (96). This is a diagnostic, not a claim that every transient or automation curve is inaudible.
- The real Chain also renders seeded stereo and dual-mono noise with a transient, changes at off-grid control edges, repeated reversals, feedback and a final plateau. Output is sample-exact across 1/64/128/512-frame partitions; repeats stay audible, the tail decays, and the callback allocation probe is scoped around the replay.
- Re-rendered nine [fixed Delay float pins](evidence/free-delay-static-f32-20261119.sha256) and nine [historic Glitch WAV pins](evidence/glitch-legacy-wav-20261119.sha256); all match. No media was committed or transferred.

## Source keyboard scope

Source is now a JUCE keyboard-focus container: its explicit Tab order stays inside the visible overlay instead of interleaving controls underneath. If a family change or restore hides a currently focused slice or grain control, Source directs focus to the layer selector **only when Source owns focus and has a peer**. Nothing new binds global keys. The offscreen test exercises the JUCE traverser in both directions, verifies inactive controls are skipped, and retains the existing local Escape and project-readback checks. It does not simulate Windows native key delivery, popup Escape, return focus or DPI; those remain in the [native acceptance matrix](WINDOWS_ENGINEERING_GATE_20261119.md#native-source-keyboard-acceptance-not-yet-run).
