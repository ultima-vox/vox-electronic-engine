VOX FX — consolidated listening review / A120 + B56 / zero approved

This is a review bundle, not a Factory installer or release. It contains 176
unaltered solo references, 176 portable presets, two original procedural
sample WAVs, audition settings, provenance and an editable review matrix.
No synthetic arrangements are represented as production listening evidence.

Review in a real arrangement:
1. Select by role and arrangement slot in arrangement-review.tsv. Log an
   arrangement identifier, tempo/key and the exact section tested. Start
   with the native clip or preset at its documented audition settings.
2. Compare the same passage with and without FX at fixed monitor gain. If
   masked, audition and record FX-path gain (e.g. 6 dB steps), headroom, mono
   translation and whether the kick, bass, lead or phrase exit is obscured.
   Leave source/reference WAVs unnormalized and unchanged.
3. For held modes test actual note lengths/release and Loop seams. For bar
   cues use a playing 4/4 host. For Sequence check real clock and exported
   trigger timing. Solo bounces are finite references, not host acceptance.
4. Rule on musical placement and rights separately from technical hashes.
   Record a result such as revisit, reject or owner-approved only after
   actual listening; blanks and not reviewed are not approval. Prioritize
   quiet Tangent Iris, Glass Estuary and Dust Shutter for masking checks.

Portable files leave receiving host base values unchanged; apply the relevant
Wave A audition or Wave B settings evidence. If a source path cannot resolve,
relink the exact bundled source with the listed SHA-256, not a substitute.

This archive is prepared for an authorized private destination only. Verify
SHA256SUMS after transfer; do not upload to public Git or deploy it publicly.
