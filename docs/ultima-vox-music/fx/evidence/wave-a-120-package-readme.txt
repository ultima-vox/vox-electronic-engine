The root WAVs are complete 48 kHz / 24-bit stereo reference renders of the
built-in Programs (including effect tails); they are not peak-normalized.
Use manifest.tsv to navigate by role, style, use, timing, tonality and provenance.

presets/ contains the corresponding portable .voxfx structures. Open them
through VOX FX's user preset browser. Imports intentionally preserve the host's
automation bases. To compare with the reference, start with a fresh instance
and set the BPM, MIDI note / velocity, seconds parameter, output and the FX
wet / amount values from audition-settings.tsv (wet and amount are 0–1).
Seconds is the host duration parameter even when the Program is timed in bars;
Sequences include one pattern cycle and the final trigger's allowed tail.

in-context/ supplies eight synthetic backing A/Bs (one per role, same backing
without/with the cue). The review trim is in context-metrics.tsv. These gain
adjustments are for these mix fixtures only, not stored as preset changes.
Please listen for a useful musical function, attack, masking, stereo/mono
impact, tail interaction with the next section, and perceptual duplication.
Report by stable ID; loudness-matched comparisons are suggested. The numerical
checks do not approve any file, and no external samples are included.

SHA256SUMS covers the files within this package. Wave B staging is tracked
separately and not included. Do not distribute this as approved factory stock.
