## Behavioral changes in this package

- **Granular scheduling:** instead of scanning up to 64 entries for each admission attempt, a 64-bit occupancy mask finds the first free slot or detects full capacity without a search. Saturation still drops the new grain, not a playing grain. A prototype that also walked the mix by set bits showed slower paired Linux results; the candidate keeps the ordered mixer loop. Lowest-slot assignment, summation, interpolation, window, retirement and lease transfer remain unchanged. The narrower optimization does not establish a cause for the historical CPU miss.
- **Layer drag and project restore:** before, a gain/pan/start/span thumb held when the host restored a project could continue editing the restored Program. The drag now carries the revision from its start through the writer-side guard; timer readback cannot re-arm it. Releasing the drag shows the restored value; a fresh drag works normally. This local gesture test is not a claim about real window focus or menus.
- **Gate tooling:** exact PR head for the explicit FX suite, concrete test timeout and required bundle inventory, with optimized PDBs and one bounded CDB replay per failed historical test. No changes to eligibility, Save or audio delivery.
