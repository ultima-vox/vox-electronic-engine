## Что закрыто в engineering checkpoint

- **Source / Motion (FX-03/04/06, FX-T02/03/08/10/15/16):** в Source у Granular — длина 10–180 ms, позиция 0–100% либо seeded Scatter, Reverse; для других семейств эти поля скрыты. В Motion — восемь значений на равных фазовых сегментах, настраиваемый ADSR и явное применение. Attack/decay/sustain влияют на маршрутизированный голос; NoteOff у held voice с активным custom ADSR задаёт музыкальный release. Panic/steal сокращают его до 5 ms без скачка коэффициента. One Shot и конечный экспорт остаются конечными auditions, не моделируют физический MIDI key-up. Нативно испытаны apply, host save/restore и отказ устаревшего gesture/draft. FPRG7 / FMOD3 сериализуются только при отличии от legacy; default write по-прежнему FPRG6 / FMOD2. Старые state/portable мигрируют; 56 прежних solo WAV совпали побайтно.
- **Program/Preview (FX-01/02/05, FX-T01/04–07/09/11/13/14/16):** на новом коде повторены прежние standalone, четыре worker tests, нативные restore/capture/browser и stress. Семь 48 kHz, 240 BPM случаев callback↔float32 capture (шесть режимов и независимый Pattern, переменные блоки) сохранили `max error = 0` по обоим каналам. Это не DAW bounce/transport acceptance. Полная матрица до этого инкремента — [предыдущий checkpoint](CAPTURE_WAVE_A_HANDOFF_20261119.md); статус непроверенных режимов/сценариев не повышается автоматически.
- **Wave A (FX-T12/19): 120 review-only / 0 утверждено**, 64 новых отдельными партиями, 15 в каждой из восьми ролей. Режимы One Shot/Gate/Continuous/Loop/Sequence/Transition: `53/17/12/9/15/14`; 16 style labels, Daylight/Balearic/Uplifting/Progressive Tech → Goa/Dark/Forest/Hi-Tech. Структура каждой добавки задана источниками, слоями, огибающими, фильтрами, FX и при необходимости рисунком нот/пауз/ratchet; нет переименованных seed-вариантов. **Wave B начала отдельный staging:** тональная/нетональная пары на 4, 8 и 16 тактов, всего 6 рендеров на 48 kHz; они не вошли в 120 и не добавлены в браузер до дальнейшего отбора. B=300, C=600; Wave C роли `110/95/65/70/105/75/55/25`. Сценарии Wave B с принесёнными пользователем assets и полный объём Wave C не завершены.

Рендер и thread CPU измерены рядом с одним и тем же callback. `VOX_FX_TIMING_THREAD_CPU=1 taskset -c 0 build/fx-native/FxRuntimeStressTests`, затем тот же вызов с `VOX_FX_STRESS_AUTHORED=1`; в третьей серии к CPU 0 привязан один дополнительный обычный CPU-bound `yes >/dev/null`, остановлен после теста. Сравнение учитывает wall и CPU одного блока; deadline прежний — `frames/rate`.
