# VOX FX — путь к единому инженерному кандидату

**Draft / HOLD / NO MERGE.** Порядок TL: FX‑03 → FX‑04 → FX‑06 → Factory Content. Разработка и ревью не ждут PowerShell preflight. [Задача оператора #164](https://github.com/ultima-vox/vox-electronic-engine/issues/164) идёт параллельно и остаётся обязательной для релизной квалификации; `pwsh` не заменяет Desktop 5.1. Ни read-only preflight, ни этот план не разрешают запуск Windows Release/CTest/validator.

Один общий пакет перед запросом разрешения на Windows: точный интегрированный SHA, [единая таблица доказательств](ENGINEERING_CANDIDATE_EVIDENCE_20261119.md), проверяемый список известных ограничений. Для квалификации отдельно требуются [Windows preflight и owner-authorized Windows x64 Release/CTest/Steinberg/Win32/FX‑T18](WINDOWS_ENGINEERING_GATE_20261119.md), затем отдельная приёмка Cubase + REAPER. Ни одна Linux итерация не объявляется готовым релизом.
