# Per-layer Granular travel — engineering development

**Draft / HOLD / NO MERGE.** Product source `678bcd501285eb49cf611c468ed1f0da3060fb91`, based directly on Draft CI head `5c2f122`; no workflow changes in this package. In **Source / Key**, select a Granular layer, turn off **Scatter** and set **Start** and **Travel**. Travel is signed percentage of the entire source over that layer's authored timeline, not percentage of its remaining length. `Start 25%, Travel +50%` uses positions from 25% to 75%; negative values move toward the beginning. New grain starts stop at the source edge rather than wrap. The grain reader inside each grain keeps its existing interpolation and wrap behavior. The change does not alter pitch, per-grain Reverse, length, density, source selection, or the global 64-grain cap. `0%` retains the fixed-start renderer; Scatter suspends (but retains) Travel and keeps the old seeded renderer. Returning to fixed mode uses the Start shown by the control, not a separately stored previous anchor.

The scan uses the existing normalized layer phase: a layer still active at the endpoint of a held Gate holds the end position, Loop restarts the authored timeline, a Continuous sustain follows its existing evolving phase, and tempo changes in bar-based events use the existing event clock. A note keeps its captured Program and external sample lease; an edit changes later notes only. The calculation runs only at grain admission with a fixed start, using the existing gain envelopes and grain pool.
