# VOX MUSIC · Owner handoff

**Status:** browser reference candidate for the single owner visual review. Native Gate 1 final sign-off is pending. Nothing here is a release or Production PASS.

**Open:** Arena → **VOX MUSIC — Instrument Workbench**. By default it opens Beatmaking in VOX Drums. [Local start and test commands](../README.md) · [Source audit](SOURCE_AUDIT.md) · [Evidence / manual review](VERIFICATION.md) · [Native porting map](JUCE_PORTING_MAP.md).

## Browser audio and limitations

Verify with an explicit play/audition gesture in a Web Audio browser. Sixteen synthesized demo voices and 24 donor PCM recipes are procedural browser fixtures, not native algorithms or authentic factory kits. Audio timing uses a small browser lookahead; excess stall/background tab throttling may pause or delay previews. Output taps are measured with rolling Web Audio analyser windows. Pad/bus peaks are analyser mono summaries; Main splits L/R pre-device after browser returns. Device/driver sample peaks, true-peak oversampling, final gain and clipping are not measured. Stop cancels future pattern events and lets current tails finish; Panic cuts active voices and resets delay/reverb state. Browser sessions do not store imported audio across reload. Local layouts are intentionally detached from transport, clips and sound settings.
