# Archive

Historical material is kept here to remove obsolete instructions from the working surface.
Do not treat archived CANON/master/agent documents as active requirements.
Current entry point: [documentation](../docs/README.md).

The archive is retained in Git, outside all active CMake source lists.
No history rewrite or source-content deletion was performed.

## Contents

- [Electronic Engine archive](electronic-engine/INDEX.md).
- Original old UI/product-split specifications and checkpoint records.
- Original project README and agent-context/workflow snapshots.
- Inactive Kick/MATCH source, tests and UI.
- Original draft design proposal.
- Snapshots of GitHub issues #10/#11, with original body, title and retrieval metadata.

## Integrity

[manifest.json](electronic-engine/manifest.json) records original and archived paths,
SHA-256 of each file, and whether it was moved or snapshotted.
The archived files are preserved byte-for-byte. Do not fix links or edit historical policy
inside those files; use the current documentation instead.

Restore individual files deliberately from Git/archive after dependency/migration review.
The presence of old Kick source is not evidence that Full-on Drums has been implemented.
